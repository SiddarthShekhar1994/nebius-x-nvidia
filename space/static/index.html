Keeper · live demo

Your inbox, sorted and acted on.

Keeper is a personal assistant for students. It sorts email, tracks internship and job applications, puts deadlines on the calendar and drafts replies for you to send yourself. This page runs Keeper's real code. NVIDIA Nemotron 3 models on Nebius Token Factory make every call.

  • Checking the model connection
  • Gmail and Google Calendar are stand-ins kept in memory, so you don't connect an account and nothing is ever sent.
  • The demo clock is set to the week of the story.

Send Keeper your own email

Keeper only moves the tracker when an email names a company and role you track, so run step 1 first. It only schedules explicit times such as 2026-11-20T17:00:00Z, and it never acts on mail with scam warnings. Don't paste real or private email: the text goes to the model.

The real Keeper runs as a Hermes agent inside an NVIDIA OpenShell sandbox, set up with NemoClaw, on a real Gmail inbox and Google Calendar. The sandbox's network policy lets it read mail, add labels and save drafts, and blocks sending. Every email on this page is synthetic or written by you, and each visit gets its own temporary copy of Keeper.
